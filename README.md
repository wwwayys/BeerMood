# BeerMood

Вы заходите в магазин, стоите перед холодильником двадцать минут, выходите с тем же пивом, что и всегда. **BeerMood** решает эту общечеловеческую трагедию: называете настроение, погоду, бюджет и желаемый вкус — программа выдаёт пиво.

## Что это вообще

Консольное приложение, которое подбирает пиво по четырём критериям:

- **Настроение** — спокойное, пикник, после учёбы (да, это официальный тег)...
- **Погода** — жарко, солнечно, шашлыки (это тоже погода, не спорьте).
- **Бюджет** — от и до, в рублях.
- **Вкус** — лёгкое, солодовое, освежающее и прочая поэзия с этикетки.

## Как работает сиё чудо?

- **Бинарное дерево поиска** — чтобы найти пиво по цене.
- **Инвертированный индекс** — чтобы за O(1) узнать, где спрятано всё «легкое».
- **Очередь** — выдаёт рекомендации по одной, как сомелье, который вам не доверяет.
- **Стек отмены** — `Ctrl+Z` для жизненных решений. Передумали брать крепкий стаут? Кнопка 8.

## Меню (главный экран)

```
========== BeerMood ==========
1. Показать текущий список напитков
2. Сортировать напитки
3. Фильтр по бюджету
4. Фильтр по настроению
5. Фильтр по погоде
6. Поиск по вкусовому ключевому слову
7. Перейти в режим подбора рекомендаций
8. Отменить последнее действие
9. Сбросить все фильтры
0. Выйти
```

## Режим подбора рекомендаций


Режим рекомендаций (пункт 7) — для нерешительных: накидываете фильтры, а пиво вам подносят по одному, пока очередь не кончится. Драматично.
После выбора пункта 7 открывается отдельное меню:

```
========== BeerMood: подбор рекомендаций ==========
1. Фильтр по бюджету
2. Фильтр по настроению
3. Фильтр по погоде
4. Поиск по вкусовому ключевому слову
5. Показать следующую рекомендацию
0. Вернуться в основное меню
```

## База данных

113 сортов, заботливо собранных с полок «Красное&Белое», «Ароматный Мир» и «Метро». Цены — иногда **учебные**: в реальном магазине будет другое число, и, скорее всего, больше. Готовьтесь!

## Дисклеймер

Пейте ответственно. BeerMood — это про настроение, а не про количество. Программа умеет отменять последнее действие, печень — пока нет.
